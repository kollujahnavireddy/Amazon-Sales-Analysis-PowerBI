# Amazon Sales Analysis Dashboard | Power BI

## Project Overview

Developed an interactive Amazon Sales Analysis Dashboard using Microsoft Power BI to analyze sales performance, product categories, customer reviews, and business trends.

## Tools & Technologies

* Microsoft Power BI
* Microsoft Excel
* DAX
* Data Cleaning
* Data Visualization

## Key Performance Indicators (KPIs)

* Year-to-Date (YTD) Sales
* Quarter-to-Date (QTD) Sales
* YTD Products Sold
* YTD Reviews

## Dashboard Visualizations

* YTD Sales by Month – Line Chart
* YTD Sales by Week – Column Chart
* Sales by Product Category – Text/Heat Map
* Top 5 Products by YTD Sales – Bar Chart
* Top 5 Products by YTD Reviews – Bar Chart

## Key Features

* Interactive dashboard
* Sales performance monitoring
* Product category analysis
* Monthly and weekly sales trends
* Top-performing product identification

## Files Included

* `Amazon_Sales_Analysis.pbix` – Power BI dashboard.
* `Amazon_Combined_Data.xlsx` – Dataset.
* `Dashboard-Screenshots/` – Dashboard previews.

## How to Use

1. Download the `.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Explore the interactive visualizations and KPIs.

## Project Objective

To analyze Amazon sales data and transform raw data into meaningful business insights using interactive Power BI visualizations.
